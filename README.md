# OracqVerify

Lean verification of programs generated by [Oracq](https://github.com/IAI-USTC-Quantum/oracq), including semantics and resource counts for the same serialized program.

The development plan is tracked in [qatlib-dev #554](https://github.com/quantum-atlas-ai/qatlib-dev/issues/554) and the [joint project](https://github.com/orgs/quantum-atlas-ai/projects/3).
